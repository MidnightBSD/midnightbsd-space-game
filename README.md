# midnightbsd-space-game
A space shooter game

Based on Allenroids by Allen Smith.  The original title was freeware.  This is licensed under the 2 clause BSD license.

## Requirements

The game uses an SDL2/OpenGL 3.3 renderer.  Install the development packages
that provide:

- SDL2
- SDL2_ttf
- OpenGL 3.3 (core profile) headers and libraries
- CMake 3.10 or newer and a compiler with C++20 support

FreeGLUT is no longer required.  Roboto is bundled under `assets/fonts/` for
the in-game text renderer.
